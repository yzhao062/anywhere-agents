# Two sources, two uses

Yue Zhao explicitly selected the [Qwen4-Max article](https://qwen.ai/blog?id=qwen4-max) for its figures and visual style and [Chen Liu's figures4papers](https://github.com/ChenLiu-1996/figures4papers) for plotting material. Keep the lab palette. The choices below are transferable techniques, not a requirement that every plot look like a launch graphic.

| Verified example | What to carry into a figure |
|---|---|
| Qwen [benchmark overview](https://img.alicdn.com/imgextra/i3/O1CN01d8WOyjWDWEKAxlwO_!!6000000007934-2-tps-5400-3600.png) | Six models appear in the same order across a 4 by 4 grid. Short benchmark names, capability subtitles, direct values, and a shared key make scanning possible. Select a smaller grid for a single column. Give each bar its full lab color at the score edge and fade it toward a pale tint at zero. Match the legend swatch to the score edge. Place the family logo just inside each bar tip on a small white backing. Keep the number above the tip and the exact variant in the shared legend. Label an empty slot n/a and omit its bar and logo. Keep units and honest baselines even when borrowing the spare axis treatment. |
| Qwen [token efficiency](https://img.alicdn.com/imgextra/i1/O1CN010VgwbmS9yHH6DCXk_!!6000000004985-2-tps-3060-1440.png) | Separate Work360 and Terminal-Bench panels; plot score against tokens per task and annotate measured reasoning settings. The solid and dashed series remain distinct without hue. Preserve actual token coordinates rather than spacing the settings evenly. |
| Qwen [pretraining evaluation](https://qianwen-res.oss-cn-beijing.aliyuncs.com/Qwen4-Max/pretraining-evaluation.png) | Knowledge, Code, QA, and STEM each have their own panel. Each score sits above its bar. The metric label gives the multiplier and says lower is better. Mark checkpoint differences in the key or caption when they affect the comparison. |
| Qwen [training loss](https://qianwen-res.oss-cn-beijing.aliyuncs.com/Qwen4-Max/training-loss.png) | One teal trace carries the run from 0% to 100% of training. Fine fluctuations remain visible against faint horizontal guides. Use this treatment when the stability of a long run matters. |
| Chen Liu [ImmunoStruct comparison and ablation bars](https://github.com/ChenLiu-1996/figures4papers/blob/0ddfbd3fc9892e804a3fa01ae46bd0d32617f2aa/figure_ImmunoStruct/plot_bars.py) | Align component configurations once down the left of several metric panels. Use the same row order in each panel. Start magnitude bars at zero, or use dots to show small differences. Include uncertainty only with the underlying observations or documented summaries. |
| Chen Liu [RNAGenScape sweep](https://github.com/ChenLiu-1996/figures4papers/blob/0ddfbd3fc9892e804a3fa01ae46bd0d32617f2aa/figure_RNAGenScape/plot_sweep.py) | The script places measurements at optimization steps 1, 5, 10, 20, and 40. Preserve their numeric spacing, carry each condition across metric panels, and label the direction of success rate. |
| Chen Liu [VIGIL radar plot](https://github.com/ChenLiu-1996/figures4papers/blob/0ddfbd3fc9892e804a3fa01ae46bd0d32617f2aa/figure_VIGIL/plot_comparison_radar.py) | Keep unobserved spokes missing when adapting the script, which fills them before scaling. Per-spoke labels and point markers make a profile easier to read. The script rescales each benchmark separately: disclose that mapping if using this form. Use aligned dots or small multiples when the reader needs exact differences; polygon area has no shared metric. |

The Qwen page loads article content dynamically; its [official article feed](https://qwen.ai/api/v2/article/?language=en-US&path=qwen4-max&type=qwen_ai) supplies the captions and asset URLs. Use the reference artwork to study the design. Implement an original figure from the task's inputs. Before reusing upstream code or art, check the [license at the inspected revision](https://github.com/ChenLiu-1996/figures4papers/blob/0ddfbd3fc9892e804a3fa01ae46bd0d32617f2aa/LICENSE) and file-specific notices.
